# Единый проект мониторинга безопасности

Объединённый проект из трёх компонентов:
1. **CLIP-модель** (model.py) - базовое распознавание сцен fight/fire/crash
2. **MMAction2** (mmaction2-main/) - продвинутое распознавание действий на видео
3. **OpenPose** (openpose-master/) - детекция скелета для визуализации при тревоге

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура

- `app.py` - Streamlit приложение с интеграцией всех трёх модулей
- `model.py` - CLIP модель + ActionModel для mmaction2
- `skeleton_detector.py` - обёртка над OpenPose
- `settings.yaml` - настройки меток для CLIP

## Использование

При запуске приложение автоматически определит доступные модули:
- CLIP всегда активен (основа)
- OpenPose - если найдена сборка (скелетный анализ при тревоге)
- MMAction2 - если установлен (распознавание действий на видео)
